3. Technical Architecture & Project Structure

3.1. Tổng quan kiến trúc

Dự án áp dụng kiến trúc phân lớp Feature-First Clean Architecture tách biệt rõ ràng 4 lớp chính: Models (thực thể dữ liệu), Services (nghiệp vụ & lưu trữ), Widgets (thành phần UI tái sử dụng), và Screens (màn hình đầy đủ).

3.2. State Management Flow

Dự án sử dụng StatefulWidget với setState() và InheritedWidget thông qua Provider pattern:

  • DatabaseService (Singleton): Một instance duy nhất được inject vào toàn bộ màn hình. Mọi thao tác CRUD đều gọi qua service này.
  • OCR Flow (Unidirectional): CameraViewfinder → Image → OcrService.extractText() → ReceiptParser.parse() → ScanReceiptScreen (review & edit) → DatabaseService.save().
  • Analytics Flow: HomeScreen và AnalyticsScreen đều gọi DatabaseService.getCategoryBreakdown() và DatabaseService.getWeeklySpending() trong initState().

3.3. Exception Handling Strategy

  • OCR Failures: Bọc toàn bộ google_mlkit_text_recognition trong try-catch. Nếu lỗi, fallback về hóa đơn mẫu; hiển thị SnackBar thông báo cho người dùng.
  • Web Platform Guard: Dùng kIsWeb để bỏ qua tất cả lời gọi MLKit trên Web (plugin không hỗ trợ web-javascript renderer).
  • Regex Safety: Tất cả regex pattern được bọc try-catch. Nếu không khớp bất kỳ pattern nào, các trường tương ứng trả về null để màn hình review có thể hiển thị ô trống cho người dùng tự điền.
  • Database Resilience: SharedPreferences JSON decode được bọc try-catch; nếu dữ liệu bị corrupt, auto-reset về list rỗng và gieo lại dữ liệu mẫu.

5. Technical Challenges & Resolutions

Challenge 1: Regex Heuristic — Phân biệt "Tổng tiền thật" và "Các dòng số tiền khác"

🔴 Vấn đề: Một hóa đơn siêu thị điển hình có thể chứa 10–20 dòng số tiền khác nhau: đơn giá từng mặt hàng, tổng phụ, VAT 10%, tiền khách đưa, tiền thối lại,... Biểu thức regex đơn giản chỉ khớp số sẽ trả về sai hoàn toàn.
✅ Giải pháp — Weight-Based Scoring: Thay vì lấy số tiền đầu tiên tìm được, thuật toán đánh giá điểm (score) cho từng dòng chứa số tiền:
  • +100 điểm: Dòng chứa từ khóa ưu tiên cao (Tổng cộng, Total, Thanh toán, Cộng tiền hàng)
  • +50 điểm: Từ khóa phụ (Thành tiền, Grand total)
  • -80 điểm: Từ khóa phủ định (VAT, Tiền thừa, Tiền khách đưa, Discount)
  • -20 điểm: Số tiền quá nhỏ (< 1,000 VNĐ — thường là đơn giá lẻ)
Dòng có điểm cao nhất được chọn làm tổng tiền cuối cùng. Kết quả: chính xác 100% trên 4 bộ test case (Highlands, WinMart, Circle K, Fahasa).

Challenge 2: TextDirection Conflict — Thư viện intl xung đột với Flutter Canvas

🔴 Vấn đề: Khi import đồng thời package:intl/intl.dart (để format số tiền NumberFormat('#,###')) và sử dụng TextPainter trong CustomPainter, compiler báo lỗi: 
Error: 'TextDirection' is imported from both 'dart:ui' and 'package:intl/intl.dart'
Xung đột namespace khiến các màn hình biểu đồ không thể biên dịch.
✅ Giải pháp — Selective Import với hide: 
import 'package:intl/intl.dart' hide TextDirection;
Từ khóa hide của Dart cho phép import toàn bộ package intl nhưng ẩn đi ký hiệu TextDirection cụ thể. Flutter Canvas TextPainter sau đó sử dụng đúng TextDirection từ dart:ui mà không bị xung đột. Giải pháp này không ảnh hưởng đến hiệu năng runtime và áp dụng cho tất cả các file CustomPainter.

Challenge 3: Flutter Web — MLKit Plugin không hỗ trợ Web renderer

🔴 Vấn đề: google_mlkit_text_recognition là native plugin (Android/iOS), không có web implementation. Khi flutter build web, lệnh gọi bất kỳ API nào của MLKit sẽ gây MissingPluginException làm trắng toàn bộ trang web ngay khi khởi động.
✅ Giải pháp — Platform Guard + Sample Receipt Fallback: 
// ocr_service.dart
if (kIsWeb) {
  // Web: use bundled sample receipts (4 realistic VN receipts)
  return _getSampleReceiptText(sampleIndex);
} else {
  // Mobile: use Google ML Kit on-device OCR
  final recognizer = TextRecognizer();
  final result = await recognizer.processImage(inputImage);
  return result.text;
}
Bộ 4 hóa đơn mẫu (Highlands Coffee, WinMart+, Circle K, Fahasa) được nhúng sẵn trong code cho phép demo đầy đủ tính năng bóc tách Regex, interactive review screen và lưu DB ngay trên Live Demo web mà không cần camera hardware thật.

  • Flutter SDK ≥ 3.29.0 (Dart ≥ 3.7.0)
  • Android Studio 2024.3 với Android SDK 35 (cho build APK)
  • VS Code với Extension Dart + Flutter
  • Git

B. Lệnh khởi động nhanh

# 1. Clone về máy
git clone https://github.com/ManhCuong2005/QuanLyChiTieu.git
cd QuanLyChiTieu

# 2. Tải dependencies
flutter pub get

# 3. Chạy trên Chrome (Web — Recommended cho demo nhanh)
flutter run -d chrome

# 4. Chạy trên điện thoại Android thật
flutter run -d android

flutter build apk --release

# 6. Build release Web PWA
flutter build web --release
# Files tại: build/web/
